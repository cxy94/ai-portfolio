说明
这是我的个人作品集仓库（为期16周的记录与代码）。该仓库用于保存课程任务、AI 助手协作记录与用于验证开发环境的简单脚本。

仓库结构
- README.md            仓库说明（本文件）
- hello.py             在 VS Code 中配置并运行 Python 的验证脚本
- ai任务单.md          使用 AI 对话工具完成学科任务的过程与结果记录（每次任务一个条目）

使用说明
1. 克隆仓库：
   git clone https://github.com/cxy94/ai-portfolio.git
2. 进入仓库并运行 hello.py 验证 Python 环境：
   python hello.py
